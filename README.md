# The Super Keyboard

The Super Keyboard is an amazing keyboard that lets you attach a detachable screen. 
This screen can transform into a digital notebook — and the best part is that you
can also set up your Spotify on it.
## Features
- Clickable screen
- Digital notebook mode
- Detachable, dual-side screen mount

## Usage
Using the keyboard is simple: just connect it to your computer and start typing. 
Attach the screen to take notes directly on the digital notebook.
